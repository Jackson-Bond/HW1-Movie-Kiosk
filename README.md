Guided software engineering tools practice.

# Movie Theater Ticket Kiosk
A movie theatre ticket kiosk that will allow a user to view available movies and showtimes. They can then select a seat and purchase a ticket. No seat already purchased may be purchased.


# Purchase Ticket Use Case Description
1. The customer selects a movie.
2. The customer selects a showtime.
3. The system displays the available seats for the showtime.
4. The customer selects a seat.
5. The system displays the ticket price.
6. The customer confirms the ticket price.
7. The system processes the customer's payment.
8. The system creates the ticket and changes the seat to unavailable.
